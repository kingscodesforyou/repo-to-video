# storyboard.json 场景 Schema（v3 · 特级教师拆解 & Shotcraft 3D 运镜版）

文案子 Agent 必须严格按本 Schema 输出 `workspace/storyboard.json`，Remotion 模板据此渲染。

> **核心铁律（严禁千篇一律摆卡片）**：
> 1. **像特级教师给小学生讲课**：每个技术功能都必须先用一个小学生秒懂的生活比喻（如“课桌堆书 vs 随身错题本”、“鲜榨果汁滤掉果渣”、“不用橡皮擦涂改的日记本”），再配合专属 3D 演示动画拆解。
> 2. **严禁通篇堆砌静态卡片与箭头**：必须根据每个功能的**物理与逻辑本质**，从下方的【功能性质 → 3D 镜头选型决策表】中挑选最契合的 3D 仿真镜头！全片**任意相邻两个镜头的 `type` 绝不允许相同**。

```jsonc
{
  "repo_name": "mem0",
  "repo_url": "https://github.com/mem0ai/mem0",
  "repo_type": "RUNNABLE", // SKILL | RUNNABLE
  "video_title": "视频标题（用于封面/上传）",
  "chapters": ["开场钩子", "生活类比", "核心功能拆解", "效果实测", "三步实操", "生态百宝箱", "总结"],
  "scenes": [ /* Scene[] */ ]
}
```

## 🎯 功能性质 → 3D 镜头选型决策表（Inspired by video-shotcraft）

在编写 `scenes` 前，先分析目标项目有哪几个核心功能点，再按功能性质对号入座选择 `type`：

| 要讲解的功能/机制性质 | 必须选用的 3D 镜头 `type` | 3D 动画与教学演示原理 | 典型适用场景举例 |
| --- | --- | --- | --- |
| **痛点引入 / 概念误区对比** | `analogy_3d` | **3D 具象生活剧场**：左右双 3D 透视舞台，左边动态演示“笨办法摇晃崩塌”，右边演示“聪明办法悬浮抽卡” | 为什么 200万长上下文 ≠ 记忆（课桌堆满书 vs 随身错题本） |
| **数据过滤 / 提纯 / 转换 / 压缩** | `funnel_3d` | **3D 漏斗萃取实验室**：原始杂乱气泡沿贝塞尔曲线飞入 3D 旋转陀螺仪，废话坠入回收桶，提纯出右侧发光胶囊 | 记忆提炼（从闲聊废话里榨出“花生过敏”纯净事实）、AST 解析、编译器 |
| **状态随时间变化 / 版本演进 / 防篡改** | `timeline_3d` | **3D 时空走廊与演进桥**：3D 透视跑道展示第 1/2/3 页历史里程碑，顶部彩虹弧线连接旧状态与新状态 | Mem0 只增不删 (ADD-only) + 时间锚点推理、Git 版本演进、事件溯源 |
| **多层系统架构 / 存储分层 / 模块解剖** | `exploded_3d` | **3/4 等轴测 3D 爆炸拆解图**：三层芯片板沿 Z 轴弹簧炸开、激光立柱贯穿、悬停展示每层比喻后再蓄力合体 | 三层混合存储（一楼 SQLite 记账本 + 二楼向量库 + 三楼关系网） |
| **多路信号打分 / 路由决策 / 混合检索** | `radar_sim` | **四路侦探合议庭**：顶部发出一句提问，4 张 3D 侦探卡翻转入场、实时充能分数条，底部汇聚出最终胜出结果 | 四路混合检索（向量+BM25+图谱+时间加权）、MoE 专家路由、多维评测 |
| **使用前 vs 使用后真实效果对比** | `slider_scrub` | **3D 卷帘显微镜推拉对比**：带发光手柄的分割线左右横扫，同屏对比普通 AI 翻车现场 vs 接入后满分秒回 | 装 Mem0 前推荐花生菜谱闹乌龙 & 耗 2.6万 Token vs 装后避雷省 95% |
| **代码实操 / 命令行三步上手** | `terminal_3d` | **3D 空间终端穿梭**：透视网格地板上悬浮 3 个不同倾角的 3D 终端窗口，打字机敲出代码并附带“老师大白话便利贴” | 第1步 `pip install`、第2步 `m.add()` 存记忆、第3步 `m.search()` 查记忆 |
| **插件生态 / 技能包 / 多工具巡礼** | `carousel_3d` | **3D 环形旋转陈列馆**：多张技能卡组成 3D 旋转木马环 (`rotateY + translateZ`)，依次转到正前方聚光灯下解读 | Claude Code 5 大官方技能巡礼、支持 20+ Agent 框架生态展示 |

---

## 通用字段（每个 Scene 都有）

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一 ID，如 `s03_funnel_extract` |
| `chapter` | 所属章节名（必须出现在 `chapters` 中），用于底部章节进度条 |
| `type` | 场景类型（优先使用上方 8 种 3D 互动镜头，搭配 `hook` / `outro`） |
| `title` | 画面主标题（≤ 18 字，直白生动） |
| `narration` | 配音口播文案。**必须像特级教师给小学生讲故事**：先举生活例子，再用大白话讲清“它是怎么一步步工作的”。单场景 60~135 字。 |
| `data` | 视觉类型专属数据（必须包含 `subtitle` 一句话秒懂比喻 和 `teacher_note` 底部老师敲黑板总结） |
